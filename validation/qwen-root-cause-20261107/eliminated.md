- Pure arithmetic failure: historical 615/615 valid back-projections replay consistently. Calibration, identity and action suitability remain unverified by that check.
- Memory retrieval alone: empty-memory task 3/4 still spend the episode investigating without acting. This is not an estimate of the causal effect of memory.
- Pure latency: original task 4 seed 3 exhausts 30 requests in approximately 120.8 seconds with no action. Waiting still amplifies current budget pressure.
- Exact duplicate query caching alone: 7 exact geometry repeats across original 50, zero in short 8 and empty 10. Changed-point queries drive most exploration.
- Artifact-path ambiguity explains every failure: file read errors are concentrated in one episode per original/empty cohort; other failures have no such error.
- High segmentation confidence verifies the task referent: task 3 selects a background cabinet with a high returned score.

None of these exclusions proves a single universal root cause. See report.md for supported mechanisms and limits.
