# LIBERO Qwen Flash 持续优化协议（已获本轮明确授权）

本协议独立于旧 UniVTAC research.md。用户已明确批准自动迭代、任务8独立指令修正版和同条件v3+EEF对照。当前开始实施E；候选是否有效由实验记录决定。

## 目标与验收

- 开发目标：同一个冻结版本，在预先固定的十个任务开发初态上取得 10/10。不同版本分别成功不能拼成一个 10/10。
- 效果目标：冻结后的完整独立复测显示成功率提升，并逐任务报告覆盖、成功数/有效尝试数、百分比和成本；不把“重试到成功”算成高成功率。
- 最终评测计划：每任务五个未用于当前开发的初态，共 50 次；失败照计。若读过该批失败再修改，它转为开发/验证集，下一次终评使用新的预留初态。
- 原始 harness 保留、不重跑最初原版。历史 6% 来自不同预算，仅作历史背景。为确认本轮改动收益，拟将当前冻结 v3＋EEF 作为同预算参考，先十个配对格子筛选；有改善再在相同最终 50 格子比较。配对检查初态图像/状态指纹，交叉分配两个环境，不能把同 seed 自动当同场景。
- 任务 8 必须按下述明确条件处理；不能删除它后声称全部十任务成功。

## 本轮请求的自动迭代授权

用户已明确授权：对本轮 LIBERO 隔离候选，在下列范围内，每次先记录具体文件 diff、依据、适用范围和验证计划，然后自主实施、验证、保留或回退，无需逐次等待同意；允许无人值守持续推进，用户可随时中断。该授权是本轮对逐次审批规则的明确例外，不修改全项目 AGENTS.md，也不延伸到真机或其他项目。

允许搜索空间：

- 独立 RPent 经验正文及 MEMORY 索引；短小、带适用条件/来源/失效条件/验证状态，按需读取，不进系统提示。
- 已有或新建的观测处理程序和工具契约；原版本保留，新版本不可变发布。
- LIBERO 专用、默认关闭的候选提示、工具选择、执行/验证工作流与 robot research 适配层；优先小改动，只有机制证据表明必要时再使用工作流或多 agent。
- 若引入策略多 agent，所有执行决策仍由 Qwen Flash 作出，两个角色共享整轮预算；开发分析助手不计作目标策略模型。同步升级请求 ID/agent ID 统计，不能给每个角色重复预算。
- 对应的测试、只读回放、隔离仿真实验、结果记录、提交推送与 PR 更新。

不在自动授权内：修改官方成功条件、读隐藏物体位姿指导策略、硬编码某轮轨迹、用更强模型代做策略、覆盖原始数据/凭据、原版默认行为/全局控制器改动、真机动作。任务定义修正版必须按独立选项明示批准。预算变化先作为另一个条件提案，不混入本协议结果。

## 固定条件

- Qwen Flash，实际 profile/model 以预检为准（当前 qwen3.8-flash），enable_thinking=false。
- 每轮 600 秒、30 次模型请求、16384 输出 token 配置，两个隔离环境并行；策略多 agent 也共享这套整轮总预算。
- 远程执行；所有启动脚本激活环境之后清除六个代理变量，核实实际模型进程直连。
- 原主工作台保持原配置，不更改其 Max/原生工具选择。
- 官方判分为 evaluator；成功优先、同成功数比较所有有效轮次成本。小样本好转只是候选证据；冻结复测前不宣称方法有效。
- 所有正常模型/规划/感知失败、请求耗尽、600秒超时纳入分母。网络/实现/基础设施意外原样保留、隔离、修复后重跑同格子，通过 supersedes 关联；有效失败不允许用重跑成功替换。
- 技能的默认5分钟包装不能覆盖这里的600秒任务预算；运行器预检/启动/收尾另记，不把提前杀进程当600秒任务超时。

## 每轮流程

1. 检查前轮是否结束、代码和配置是否发生独立变化，读取完整失败证据。
2. 找到最早偏离目标的环节；提出可证伪假设和最小改动，保存 diff 与预期可观察改善。
3. 远程定向测试、历史回放、材料权限和版本检查通过后，跑受影响的1–3个任务和至少一个已有成功任务回归。尚无成功任务时不虚构成功回归。
4. 检查工具是否真正被调用、经验是否真正读到、输出是否影响决策、物理机制是否改善，再看官方结果。工具未用不能称其执行有效。
5. 无改善保留负结果并回退候选选择，不删除代码/记录；连续三轮无改善换策略，必要时评估显式工作流，再考虑多 agent，不无限重复同类提示扩写。
6. 每个获准修改验证后提交、推送、更新 PR，不自动合并；看板只标实做实测。
7. 全任务覆盖后冻结版本，做独立复测；未达到目标继续分析，不能以阶段结束冒充完成。总资源成本持续报告，不预先保证成功率必然达到100%。

## 任务 8 的明确选择

只读审计发现当前语言 `put the left moka pot on the stove`，goal 为 `On moka_pot_1 flat_stove_1_cook_region`；实际50个初态及相机投影确认 pot1 位于画面右边。不能教模型忽略任务语言以追逐错误评分。

已按用户选择在独立候选副本中将该任务唯一语言字符串改为 `put the right moka pot on the stove`，goal、物理状态和控制不改。原安装包与原实验保留。实际运行 cohort 标为 `libero_10_task-language-right-v1`（草案暂称 `libero_10_task_instruction_audit_v1`），原始 suite 名作为来源；同预算参考也使用同一修正，结果不能冒充未经修改的原始 benchmark。私有 BDDL 路径已由实际环境日志核实。

另一选项：保持原版，把任务8列为基准定义冲突，先优化其余九项；不能宣称原版十任务干净验收已完成。
