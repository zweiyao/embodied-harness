# 放置几何的独立审查：抓持偏移与容器开口

2026-11-09。只读分析与候选草案；没有运行新实验、修改工具、提示词、经验或 harness。iteration-04 的 restricted18M 仍是独立条件，不能把本文方案混入其中。

## 已知根因不是同一种几何错误

03 task 4：目标左盘采样正确，杯子也确实持稳。模型已得到杯表面与 EEF 的不同坐标，却把 EEF 目标设成盘心 XY；随后用夹爪、桌面和混合边缘点确认“杯底/对齐”，释放到盘旁。这里存在可被程序承担的关系合成，但语义点角色也有错误。

03 task 0：篮子身份保持，错误发生在篮体表面与容器功能区域之间。请求 5、10、19 的 inner-rim 参数混合内壁、外壁和桌面，工具正确返回 `inconsistent_rim`；18 的腕部桌面点算出 `measured`，模型自己拒绝了它；20 再取近侧篮沿/外壁坐标，自定中心后释放在篮沿。不存在可信开口中心，不能靠正确减法恢复。详见仓库 `validation/qwen-continuous-20261109/iteration-03/diagnosis.md` 与其中图片复核路径。

同一个篮子 mask 可以包含内外壁及篮沿；它能约束“是不是这一物体的区域”，不能证明“是不是可容纳物体的空腔”。把点对计算变成执行动作也只减少计算/采用负担，不修复错误功能区域。

## 当前 container helper 的能力及缺口

核实源码：`examples/manual-workbench/sensor_container_geometry.py`、`container_candidate.json`、`tests/unit_tests/robots/libero/research/test_container_geometry.py`。

处理链是：选定像素附近的深度样本 → 与中心样本距离一致的邻域 → 高度共识 → 世界 XY 凸包 → 面积/高度检查 → 凸包质心。可选 object-bottom 点再算点到质心、点到边界及点到沿顶高度的关系。没有视觉内缘识别、全边界覆盖检测或物体完整 footprint。

目前没有数值证据表明质心公式或坐标转换实现出错。问题在于它必须假设调用方已经给了正确内缘。不能通过调松高度/面积阈值让 03 的错误输入通过；也不能把“高度更整齐”当作语义正确。

有三个直接反例，不需要物体真值：

1. 在桌面同一平面选四个非共线点，只要面积满足原检查，就会得到 `measured`。现有数值单测本来就用合成平面验证公式，因此单测通过不证明桌面能被排除。
2. 只给一个圆形开口的短弧段：凸包仍可能有足够面积，质心靠近该弧段，不能代表完整开口。当前“同一条直线退化”的测试排不掉这种情况。
3. 对非凸开口取凸包会填掉不可通行的凹部；即使真实开口凸，质心也不一定最大化物体到边缘的余量。改用最大内接区域只在已知完整有效边界时有意义，无法修复错误/局部边界。

输出同时包含“不证明语义/完整空域”的限制和“使用这个中心作为开口”的 guidance，后者可能让条件性测量被当成已确认目标。后续如修改，宜明确区分 `surface_geometry_consistent` 与经视觉支持的 `opening_region`，但仅改措辞不能视为根因已解决。

## 假设 H1：将所持特征到目标的关系直接交给工具

最窄适用范围：物体已由图像确认持稳；在当前同一帧能识别一个真实物体特征和正确目标参考；此次动作主要为平移，姿态/抓持关系未改变。算法为现有 T 的 `EEF_xy + goal_xy - object_feature_xy`，无需再造数学。

可审查的候选入口可为一个显式的关系操作，而不再藏在批量工具的 optional 参数里：

```text
align_held_feature_xy(
  step,
  object_feature_ref: {camera, pixel, image_size},
  goal_ref: {camera, pixel_or_verified_region_ref, image_size}
)
```

这里只是接口候选，未实现。首步仍应只读返回同帧采样、编号图、所选特征的 XY 残差及合成 EEF 目标；若未来批准动作版，可调用原有 M 保持夹爪 target，原控制限制保留。原语之间不得偷偷再开爪、重抓、降低高度或触发释放。

**可证伪预测：**在独立核对点身份、确认握持与姿态稳定的样本中，首次平移后同一物体特征到目标的 XY 误差应下降；相较 EEF 直接到目标，该过程应减少 03 task 4 的系统性偏移。若特征误差不降，应检查采样身份、可见特征对应、实际运动与滑移，不能只看计算返回。

**反例与边界：**杯前壁的可见点不等于杯底中心。把前壁点对准盘心，杯中心仍可能偏半个杯宽；杯把也可能伸出支撑区。一个点对齐并不保证整个物体适合目标。物体旋转、滑移、遮挡后换了另一个“同类点”、或使用 mask centroid 因可见区域改变而漂移，都能破坏固定相对关系。目标点选在篮沿时，关系计算越精确也越可能精确移到篮沿。

因此 H1 的首个评价量是“同一可见特征误差”，最终另看支撑/容纳与官方成功。不得用 H1 通过来省略落放验证。03 正确盘点和正确杯点可以用于只读数值对照，但那不替代新闭环动作的因果验证。

## 假设 H2：开口是一块几何区域，不是空腔像素的表面深度

只适用于能看到内边界、开口可近似为一个平面、沿部有可靠深度的开放容器。选择 RGB 中开口内部像素时，该像素的深度常来自后方内壁、底部或背景；直接 back-project 再作为开口位置，会混淆不同的几何对象。

候选方法分清以下能力，不能把完整开口能力暗含在局部目标里：

- **P1：平面上的条件性目标点。**在同一帧，独立标明可信沿表面点与一个视觉上位于开口内的像素。利用沿点及匹配标定建立参考平面，将目标像素的相机射线与该平面相交。不读取该空腔像素后方物体的深度。返回“该射线在参考平面上的点”，不称为开口中心或可放置区域。
- **P1-region：可见内部子区域。**可用有序小多边形替代单个目标像素，其顶点与内部均须在图像中可确认经开口可达的内域。投影到同一参考平面后，返回“所选子区域”和其内部目标，不声称恢复了整只篮口。篮子其他部分被画面裁切不必否决这个候选；但所选子区域自身被遮挡、贴着不明边界或跨越外壁时，仍不能自证有效。这是比 P2 小的候选，可优先验证；区域质心只支持参考点目标，不证明整个所持物体有 clearance。
- **P2：开口区域及可见余量。**在 P1 之外，要求 RGB 上完整、可核对的内边界闭环，把边界射线交同一平面，形成开口区域，再选内部目标。保留实际边界，不用凸包自动补齐缺失/非凸部分；触图框、被手/物体遮挡或缺少边界时标为覆盖不足。只有这一层才有条件讨论点到开口边界的余量。

实际相机能力足够支持条件性计算：`robots/libero/tools.py:_world_from_depth` 使用当前帧 intrinsic_K / extrinsic_cam2world，当前 generated high bundle 也包含同源标定。像素约定是已校准图的 `[row,column]`，相机射线来自 `R K^-1 [column,row,1]` 和相机原点。射线与平面不相交、近乎平行、交点在相机后方或拟合病态应返回 unavailable，不补默认坐标。腕部必须使用同一帧外参。

最小输入草稿：

```text
sensor_opening_plane_target(
  step, camera, image_size,
  rim_surface_pixels,
  target_pixel_or_ordered_region,
  inner_boundary_pixels  # 完整开口 P2 才要求；不是局部目标的必需输入
)
```

拟合平面需要足够分布、可信且不共线的沿证据；若采用“近水平”任务先验，应显式限适用范围，不把它套到倾斜/变形容器。拟合误差小不证明所选平面是沿顶：一组桌面点也同样拟合很好。先验不应偷偷替代缺失的语义证据。

**可证伪预测：**当实际可见内缘与平面成立时，改变目标像素后方的观测深度、保持相机与开口几何不变，不应改变 P1 的开口平面目标；不同可见视角所选同一开口区域，应得到一致的世界区域。P2 若接受 03 的半边墙/桌面点并报告完整开口，则其前提检查失败。

**必须保留的反例：**只有篮体 mask、只有半边沿、柔软不平的篮口、多个相近层面的内外沿、透明/反射导致沿深度不可用、窄视角近乎掠射、遮挡、放入物使空域变化、容器移动。03 外部图右侧篮子被画面裁切，不能假定当前视图已给出完整开口。需要更合适的现有相机观测时，应明确请求缺失证据；此草案不自动移动腕部或执行探测动作。

上述完整性反例针对完整开口声称；P1-region 不需完整篮口，但仍需可信平面和真实内部子区域。外壁上的一个小闭环也可有正面积、平滑深度和稳定投影，不能因它几何自洽就接受为内域。将同一像素的射线交点投回原相机必然自洽，这不是独立验证；应评价模型是否在编号图中改正功能区、其他视角是否支持、动作后关系是否按预测改善。冻结 preview 引用可防止坐标重抄出错，但也会冻结错误选择，不能替代这一步。

## Footprint 与闭环：不能从可见点集偷渡完整形状

可见 RGB-D 点的 XY 范围是“观测到的部分范围”，可能缺背面、把手或被夹爪遮住的部分；它通常不是完整 footprint 的保守上界。不能把这个范围扩大一点就称为全部 clearance 已验证。完整可见轮廓、多视角对应或明确的任务族形状条件可以提供更多支持，但这些能力应逐项证明，不能读模拟器对象 pose、mesh/bbox 或 goal 真值来补齐。

更实际的最小闭环是：一次短平移后核对同一物体特征和目标区域，确认关系是否向预期变化；在降低/释放前再次检查物体相对支撑/开口的位置。它能发现 03 task 4 的仍偏盘和 task 0 的仍在篮沿，而无需声称已恢复完整六维物体位姿。不过，同一个 VLM 也可能再次误认；编号采样 overlay 的价值必须以“它看到了并纠正了什么”为证据。

建议输出先显示原图上的点、边界与功能角色，再显示数值和合成目标。当前 generated sandbox 只返回 JSON、不直接生成附带图像；若新增主机侧 overlay artifact/图像响应，属于独立、待批准的显示接口修改。不能把已有文字坐标列表等同于模型已看见 overlay。

## 独立验证与候选取舍

1. 先用既有 03/02 记录及独立人工标注的图像角色做只读反例集：正确杯点/机器人点、盘中心/盘边、真实内缘/内外壁/桌面、完整/截断开口。评价数据只用观测与标定；保持图像标注和工具输出的独立性。不得用模型自己的“rim”参数名作语义真值。
2. H1 检验关系合成与动作采用；H2 检验开口模型，不将二者首次合用的一次成功解释成任一单独机制有效。04 先给出 M 的真实采用与行为证据，再冻结后续背景。原 C 和历史失败不改写。
3. 若进行 P1/P2 数学验证，可使用合成已知相机/平面的反例（平行射线、坏外参、缺沿点、后方深度变化），验证公式边界；这只证明算术契约，不证明 VLM 能提供真实内缘。
4. 若批准闭环测试，记录：语义点正确率、有效/误接纳/误拒绝、模型是否实际查看 overlay、是否纠正而不是重复原点、同一特征误差、完整开口覆盖、握持变化、正式成功和总成本。所有新增分割、模型核对、重试都共享当前 episode 预算；不通过独立 agent 获取新的完整预算。
5. 若 overlay 看到错误仍被继续采用，纯感知工具的可选接口不足，应考虑显式证据使用阶段；若没有可用完整内边界，则 P2 应承认 unavailable，不以更松几何阈值制造成功。若 H1 有效但最终偏放未减，应检查物体参考特征是否与放置功能点对应，而非继续改减法。

最小顺序建议：先完成 04 采用筛选；随后优先用编号图把“点属于什么功能表面”变成可检查证据，再按任务 4 的条件性关系合成、任务 0 的开口平面/区域两条独立假设验证。没有理由直接引入多 agent；当前首先缺的是可信测量对象及其使用契约。
