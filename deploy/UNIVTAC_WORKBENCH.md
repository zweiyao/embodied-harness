# UniVTAC 开发工作台

使用原 RPent dashboard，另起服务以保留 LIBERO 的环境与当前会话。
`start-univtac-workbench.sh` 使用 RPent Python 运行 planner，通过独立的
`univtac-python` wrapper 启动 Isaac；不修改系统驱动或全局 Vulkan 配置。
服务器凭据引用放在 `native-univtac/workbench.json`，不提交到 Git。

- UniVTAC：远程 `127.0.0.1:8093`，本机转发 `http://127.0.0.1:18093/`。
- LIBERO：原远程 `8092` / 本机 `18092` 保留。
- 控制台 `/console`，历史 `/runs`，工具库 `/tools`。

本次仅开放 `dev-03`、`dev-04`：GPT-6 Astra、`insert_hole`、seed 2/3、
C 条件六个原生工具。每轮最多 60 次模型响应、300 个短控制命令；
单次模型等待上限 180 秒，planner 上限 3600 秒。
模型连接检查计入 80 次离线请求；所有已预留实验（含基础设施失败）计入
40 次总额度，不复用编号或自动重试。

开始页选择实验编号会填入任务、seed、模型及预算。工具选择不自动变动；
服务端检查匹配关系，在任务开始前冻结编号、配置和工具源码。
其它开发阶段与正式测试仍需完成暂定工具、Max 反馈和冻结验收，当前网页不开放。

控制台在观测/动作返回时刷新外部 RGB、腕部 RGB、双指触觉及参考图，
不是动作期间的连续视频直播。完整录像在结束时刷盘，可从历史页面播放。
触觉显示图是原生 [0,255] 浮点 RGB 的显式 RGB8 副本，原数组仍独立保存。
历史数据的缺失字段或相机外参不会由新代码补造。

启动工作台本身不预留实验，不启动模拟器。先在页面检查 GPT 连接，再保存
`dev-03` 配置，并在控制台发送 `/rpent-task univtac 0 2`；结束并核对留档后，
切换 `dev-04`、发送 `/rpent-task univtac 0 3`。每次都会启动独立模拟器和模型会话。
