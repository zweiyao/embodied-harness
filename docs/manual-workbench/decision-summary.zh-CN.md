# 任务结束后的动作决策复盘

独立复盘 agent 读取已结束的工作台任务，为每次高层动作工具调用生成一条记录，
输出 JSON 和中文 Markdown。它不参与主模型循环、不执行动作、不写经验库，
也不改变环境判分。模型使用隔离的 Codex 目录，禁用 MCP、shell、浏览器等工具。

```bash
python -m rpent.evaluation.decision_summary /path/to/finalized/task \
  --output /path/to/separate/review --model gpt-6-astra
```

在远程使用与实验相同的模型凭据，以及通过独立网络脚本选定的网络环境。
该命令继承网络设置，不切换代理，不启动仿真器。

每次请求只接收动作发生前的日志，以及此前最近一次观测或动作返回中的最多三张
RGB 图；过长的工具返回会明确标记截断。模型分别总结观测证据、主模型可见说明、
明确说出的工具选择依据、复盘推测和未知项。每项引用日志行号 `E<number>`，
归因给主模型的内容必须引用主模型的可见文字。动作后反馈由程序按 `call_id`
配对，在总结请求后单独附上，避免用后续结果解释先前决策。

JSON 保留来源哈希、动作参数、证据、反馈，以及复盘模型单独的 Token 和耗时。
已有动作报告仅在来源哈希、动作身份、模型、提示词及证据请求一致时复用。
复盘失败不改变实验结果。
报告属于运行产物，不进入经验库或公开 Git；完整录像、全部中间帧和未公开的内部
思考不会提供给复盘模型。有证据支持的解释仍不等于因果证明，日志也可能不完整。
