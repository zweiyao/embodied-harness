后三次因输入超过1048576字符而被拒，最终10轮是原生复测，不能归因工具增益。

本次继续在任务0开发，最多五次新优化。复用配置一致的原生开发基线，
每版三个实际仿真seed；只有开发改善才冻结到任务1/2各五轮，最多25轮新仿真。
不把历史图像策略请求代替仿真。系统提示、控制、官方指令和判分保持原样。

## 已修复

- maker输入去掉重复源码和重复动作回执；保留每个实测位姿、控制命令、完整调用顺序。
  marker以共享下标采样，每工具保留首中末反馈及错误；明确标记省略与精度，完整档案仍在远程。
- 给maker提供任务0逐轮成败与模型finish。之前只有汇总分数，无法直接对应模型错误的结束判断。
- 发送前按SDK实际JSON转义后的文本检查320000字符限制；输入过长立即停止，不连续消耗优化次数。
- 一个工具只承担一个关键推断，说明最多700字符、返回最多1500字符，避免重复输出多模态统计。
- 开发基线3/3时允许“维持成功、token下降20%”提前停止；不虚构成功率提高。
- 无改善候选不启动测试；有改善才冻结，测试轨迹不回流制作。新增未缓存输入统计，制作成本另计。

## 已核查的开发失败

第二版seed0/1均由模型finish(success)结束，但官方未成功。
两者理由均含“触觉变化变小、可见插入”；seed0最后相邻marker变化约0.048/0.044像素，
而相对初始参考的位移中位幅值仍约6.74/6.63像素。前者不能证明无接触或继续插入，
后者也不是标定力。最终双相机图像仍有遮挡，不能据此确认隐藏插入深度。
这是待验证的诊断方向，不把相关性视为完整物理因果结论。
