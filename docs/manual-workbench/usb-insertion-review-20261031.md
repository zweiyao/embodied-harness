# USB 插入经验：接触后重新确认夹持关系

来源实验：`35a7fbd1bfabd254f93c`，2026-10-31，Flexiv RDK，Astra high，任务“抓起u盘，插入蓝色槽中”。

## 结论与证据边界

现场观察是初始 X 方向偏后，随后下压使 U 盘在夹爪内偏转。记录支持“接触阻力增加，随后插头相对夹爪外观改变”，但没有物体姿态真值，不能精确确认初始 X 误差、滑移角度或唯一接触原因。腕部局部图像中，第 17 步及卸载后的插头外观与第 12、15、16 步不同；变化与现场报告一致。图像不能单独排除形变或遮挡影响。

该轮并未确认任务成功。虽然会话层 `state=succeeded`，实验 `outcome.json` 是 `budget_exhausted`：25 次模型响应、32 次工具调用、约 275.8 秒，`environment_success=null`、`finish=null`。不能把正常结束状态当作插入成功。

## 关键过程

以下力值取 `states.json` 的动作后观测，而非运动中的峰值；调用即时返回略有差异。

| 记录步骤 | 行为与观察 | 含义 |
| --- | --- | --- |
| 7–8 | 闭爪后开度约 3.20 mm，抬起 60 mm；模型认为金属头朝下 | 夹起不等于插入轴线已经准确对齐 |
| 12–14 | 定位插头末端宽面及“孔右侧”蓝色上表面 | 后者是实体表面点，不是孔中心；两点之差也不能说明轴线角度 |
| 15–16 | 先横移并下压 7 mm，再下压 4 mm；Z 向力约 1.83、1.52 N | 模型在接近孔口时混合横向修正与下压，难区分每种动作的效果 |
| 17 | 指令下压 3 mm；相邻观测 TCP 实际下降约 2.06 mm，Z 向力约 11.95 N | 接触负载显著上升。接口 `reached=true` 的位置误差约 0.999 mm，属于现有 1 mm 到位容差；不代表插头顺利进入 |
| 18–19 | 抬起卸载，Z 向力回到约 −1.43、−1.55 N | 卸载有效，但不能证明物体已回到原先夹持姿态 |
| 20–22 | 绕基座 Z 轴转 −0.12 rad（约 −6.88°），随后重新测量插头点和槽旁表面点 | 确实重新定位了点；没有记录对插头轴线及夹持稳定性的独立复核。绕 Z 调整不能一般性解决倾斜 |
| 23–24 | 横移 X +3 mm、Y −0.5 mm 并下压 5 mm，再下压 3 mm | 到预算上限，未记录可核验的完成判断 |

`set_gripper` 的 18 N 左右是夹爪反馈，与 TCP 外力是不同测量。第 16–18 步夹爪开度仍约 3.20 mm，反馈力约 18.42→18.53→16.45 N；固定开度不能证明没有物体滑移。

## 新工具在本轮的作用和边界

`sensor_alignment_contact` 共调用三次：比较 12→15、12→15→16 和 20→23。没有一次覆盖阻力突增的第 17 步，因此不能用其先前 `undertravel_with_force_rise=false` 排除后续接触。

工具输出明确是选定表面残差与条件性 TCP 外推，不是孔中心或物体轴线。第 12 步 X 残差约 0.406 mm，仅表示插头采样表面与孔右侧采样点的 X 差；不能据此宣布插头与孔已经对齐。第 20 步之后使用了新定位点，不能将该轮描述为始终沿用旧锚点；问题是重新取一个点仍不足以恢复物体姿态信息。

## 已落地的经验

经验保存在 `memory/flexiv/global/insertion_grasp_revalidation.md`，按 RPent YAML 元信息格式标记 `scope: global`、`kind: failure`、`confidence: single-shot`，由 `memory/flexiv/MEMORY.md` 登记标题和适用条件。具体经验不进入系统提示词；Flexiv 的任务提示仅提供索引入口，启用 `read_text_file` 后按需读取相关条目。动作接口不变。

1. 抓起后记住插头、物体轴线相对两指的关系。
2. 近孔时用两路图像分别判断横向偏移、轴线倾斜和绕插入轴的旋转；深度辅助测距，不把孔旁表面当孔中心。
3. 接触附近将横向／角度修正与推进分开；每次推进比较物体进展、夹持外观和相对未受载状态的力变化。
4. 受阻后先卸载，再检查夹持关系。若滑移，旧 TCP 到物体的估计作废，重新检查尖端和轴线；夹持不稳时在可见支撑面放稳再重抓。

这是策略经验优化，不是新增保护门槛。没有降低全程速度、缩小动作上限、修改到位容差或增加夹持力，也没有新增一个重复几何查询的工具。上述单次力值不作为通用接触阈值。

## 后续验证

本次复核和经验库更新不启动机械臂。下一轮应检查：是否在第一次接触前分别完成位置与姿态检查；遇阻是否卸载并检查物体相对夹爪变化；是否出现重复硬压或无依据旋转；最终插入证据及决策数。尚未证明该经验提高成功率。
