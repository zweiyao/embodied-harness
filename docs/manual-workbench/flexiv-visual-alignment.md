# 真机末段对齐与反馈精简

`sensor_visual_alignment`读取同一相机的 1–4 个已有 RGB 观测。模型先在原图上指定插头和开口各一组“可见中心、轴向点”；两点至少相隔 8 像素。工具计算投影中心差、轴线夹角和动作后变化，不使用槽边表面点替代孔中心。

工具使用局部归一化图块匹配，搜索范围 24 像素，并检查匹配歧义和正反向误差。输出 `tracked` 表示跟踪结果；`tracking_lost` 表示不能继续使用当前点。遮挡时应观察当前图并重新选可见点，通过 `reselected_axes` 提交；该结果标为 `reselected_current`，不冒充自动识别。没有可见依据时应换视角或重新取清晰观测，不能填写想象的孔中心。

像素 x 向右、y 向下；角度按图像顺时针计算并折叠到 ±90° 内（轴线无方向）。负的距离变化代表投影距离缩小。相邻动作的实际 TCP 位移作为独立证据返回，不能把像素直接换成基座毫米，也不能仅凭投影重合判断入孔。旋转、透视、遮挡和滑移可能改变投影。

该工具复用现有 `run(frames, params)`、Docker 沙箱、版本冻结和网页工具库。输入适配器只读取指定相机 RGB 与实测 TCP/动作，不读隐藏真值或任务判分；无需依赖 `localize_target`。发布不会自动选入实验。下一轮可在感知区选它替换旧的对齐工具，保持一次只试一个新增工具。

真机常规反馈同时省略重复的相机设备序列号、进程号和多组时间戳。原始图像、完整观测留档、标定几何、帧编号、数据年龄、同步偏差、TCP、力觉和控制器返回不变。完整相机信息仍可通过现有观测设置查询读取。经验更新在 `memory/flexiv/global/insertion_local_alignment.md`，由 `memory/flexiv/MEMORY.md` 索引，系统提示词未添加具体任务经验。
