# 插入受阻后检查夹持滑移与物体轴线

## 适用条件

来自 Flexiv RDK 真机 USB 插蓝色槽的一轮失败复核。适用于能够观察夹持物体、手指及槽口的接触插入任务。这是单轮经验，尚未通过后续实验验证成功率收益。

## 建议做法

1. 抓起后观察插头尖端、物体轴线相对两指的位置，建立夹持参考。
2. 近孔时用双视角分别判断横向偏移、轴线倾斜及绕插入轴的旋转。对齐实际插头与槽口，再推进；孔旁表面的深度不是孔中心。
3. 接触附近将横向／角度修正与推进分开。每次推进后比较物体进展、夹持外观和相对未受载状态的力变化。
4. 阻力上升而无明确插入进展时，先沿已知退出方向卸载，再检查物体是否在两指间滑移。
5. 若发生滑移，废弃旧 TCP—物体关系，重新观察尖端和轴线；重新取一个表面点不能验证姿态，开度不变也不能证明没有滑移。夹持不稳时，在可见支撑面放稳后重新抓取。

## 来源证据与限制

实验 `35a7fbd1bfabd254f93c`，2026-10-31，Astra high，任务“抓起u盘，插入蓝色槽中”。第 17 步指令下压 3 mm，相邻动作后观测中 TCP 下降约 2.06 mm，Z 向外力约 1.52→11.95 N；腕部图像中插头相对夹爪外观发生变化，与现场报告的夹持偏转一致。不能仅凭图像排除形变或遮挡，也无法精确还原初始 X 偏差。

卸载后模型绕基座 Z 转约 −6.88°，并重新取插头及孔旁表面点，但未记录物体轴线和夹持稳定性的独立复核。该轮 25 次响应预算耗尽，未确认插入成功。

原几何工具给出的是选定表面点残差及基于刚性夹持假设的 TCP 外推，不测量孔中心或物体轴线；其三次调用未覆盖第 17 步，先前无接触标志不能排除后续受阻。不要由力反馈单独推断唯一的 X/Y 修正方向，也不要把上述单次力值设为通用阈值。
