# 孔口附近先检查角度与双向偏差，再验证推进

## 建议做法

1. 用三维定位靠近槽口后，改为比较实际插头与孔口的相对边缘、中心及方向。双视角互相补充；孔口遮挡时不要把可见表面点当作孔中心，也不要把图像方向直接当作基座 X/Y。
2. 每次动作返回的新图像都用于复核。横向近似对齐只是待验证假设；接触后若没有明确进展，重新检查两个横向分量和角度，不要仅重复下压。
3. 接触附近逐步缩小推进量，将横向修正、旋转和下压分开。根据可见偏差选择一个分量调整，再比较偏差是否减小。若方向不清楚，先卸载，在有可见间隙的位置用一次小幅单轴试探建立图像变化与运动方向的对应；偏差变大则撤回，不盲目扫描或同时改变多个分量。
4. 比较目标位姿、实测位姿及插头本身的进展。根据当前接口反馈或运行配置核对到位容差；返回 reached 不证明细小调整已经充分执行，需检查实际位移；不能将 TCP 到位等同于插头入孔。
5. 阻力上升而无明确进展时，先退出卸载，再检查夹持及相对对准。调整后再试探推进；不要在持续受载时横向拖动，也不要根据单个力分量决定唯一修正方向。
6. 左指触觉可辅助比较夹持接触变化，不能单独判定插入成功或世界坐标修正方向。只比较同一次采集会话的有效帧；断连后的跨会话数据不能作连续位移证据。触觉变化明显时结合双视角检查物体是否相对手指移动。
7. 深度定位连续失败时，改变观察依据而不是反复调用同一失败选点，给末段调整保留决策次数。最终分别报告入孔证据、夹持状态和剩余不确定性。

## 减少重复试探

- 在清晰的同帧图像中分别检查轴线夹角和两个投影位置分量。角度明显不符时先处理角度，再复核位置；不能用某一轴接近零代替完整对齐。
- 用同一组可见对应特征比较动作前后。遮挡后重新选当前可见特征，并说明参照改变；不要继续外推已不可见的孔中心。
- 每次修正记录是否使图像残差减小，结合实际位移判断方向。图像像素、基座轴和触觉图像轴分开解释。
- 同帧同点的深度查询直接复用结果，不重复查询；每次动作已有反馈图像时，只有缺失、模糊或需要新的时刻才再次观察。
- 靠近孔口后为修正后的推进和确认保留交互预算；没有新对齐证据时，不重复同一方向下压。

## 来源证据与限制

来源实验：`6d95c6b7c96121606619`、`8690a1d26b6627d231d9`，均因决策预算耗尽结束，未确认插入成功。具体轨迹和测量数值见对应实验记录。

记录中出现接触受阻后反复推进、定位失败及末段修正后缺少推进验证的情况。图像支持接近孔口或投影改善，但不能证明实际间隙、完整对齐或插入完成；操作员报告对准也不能代替插入证据。

部分来源记录存在触觉断连或未使用触觉比较，不能据此认定触觉带来了修正收益。以上判断方法仍待后续验证，未证明成功率或成本改善。
